1. Xác định bài toán

- Input là gì?
- Output cần dự đoán là gì? y/n
- Đây là Classification, Regression, Clustering hay bài toán khác? Binary Classification
- Metric nào dùng để đánh giá? Accuracy, Precision, Recall, F1-Score, ROC, AUC  
- Model sẽ được sử dụng ở đâu?

- Database

- Sensor
- Log
- Dataset công khai...

3. EDA

- Tìm hiểu dữ liệu:
- Có bao nhiêu dòng/cột?
- Kiểu dữ liệu?
- Missing value?
- Outlier?
- Phân phối dữ liệu?
- Class có mất cân bằng không?
- Feature nào có tương quan với target?
